# Личный кабинет

Основа веб-приложения на Node.js 24 и SQLite без внешних зависимостей.

## Разработка

```sh
cd /workspace/LK
npm test
npm run dev
```

Сервер слушает порт 3000. `npm start` запускает его без наблюдения за файлами.
Отдельная сборка не нужна. База автоматически создаётся в `data/lk.sqlite`.

Доступны регистрация по e-mail и паролю (12–128 символов), вход, профиль и выход.
Сессия действует 7 дней и сохраняется после перезапуска. E-mail приводится к нижнему регистру.
Пароли хешируются scrypt с индивидуальной солью; в базе хранится только хеш токена сессии.
Тест проверяет весь цикл авторизации, сохранение сессии при перезапуске, ошибки ввода,
дубликаты e-mail, ограничение запросов и отклонение запросов с другого origin.

## Настройки

- `PORT`: порт, по умолчанию `3000`.
- `HOST`: интерфейс, по умолчанию `127.0.0.1`.
- `DATABASE_PATH`: путь SQLite, по умолчанию `data/lk.sqlite` относительно рабочей директории.
- `NODE_ENV=production`: включает Secure-cookie; требуется HTTPS перед приложением.

## Границы текущей версии

Регистрация создаёт аккаунт без отправки писем и подтверждения владения адресом.
Перед публичным запуском нужны подтверждение e-mail, восстановление пароля через
почтовый сервис, HTTPS, резервное копирование базы и настройка лимитов на reverse proxy.
Текущий лимит — 20 запросов регистрации/входа в минуту на IP в одном процессе;
за reverse proxy он считает адрес прокси. Для нескольких экземпляров нужны общие лимиты
и согласованное хранилище. Интерфейс и API работают на одном origin.

API: `POST /api/register`, `POST /api/login` (JSON с `email`, `password`),
`GET /api/me`, `POST /api/logout` (JSON `{}`). Авторизация передаётся cookie.
